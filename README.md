# English OS

Website học tiếng Anh cá nhân cho công việc TMĐT và cuộc sống: https://quanjanu-prog.github.io/English/

## Cấu trúc
- `index.html`: bản build, GitHub Pages phục vụ trực tiếp. Không sửa tay.
- `src/`: mã nguồn (dữ liệu, giao diện, kết nối Supabase). Sửa ở đây rồi chạy `python3 src/build.py` để tạo lại `index.html`.
- `supabase/english-os-setup.sql`: cấu trúc cơ sở dữ liệu, phân quyền, chặn tự duyệt.

## Phạm vi hiện tại
Giai đoạn 1 – Nền tảng (tháng 1–3, 0 → A1, ~100 giờ). Giai đoạn 2–4 chưa làm.
